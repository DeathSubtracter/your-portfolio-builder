Homepage assets:

- `menu-pixel.otf`: Minecraft font by Idrees Hassan, https://github.com/IdreesInc/Minecraft-Font. Unmodified, bundled under the SIL Open Font License in `menu-pixel.LICENSE.txt`.
- `menu-panorama.png`: classic Java title panorama face, from `assets/minecraft/textures/gui/title/background/panorama_2.png` in https://github.com/InventivetalentDev/minecraft-assets/tree/1.12.2. Original Minecraft artwork by Mojang, used as the shared backdrop fallback.
- `panorama/0.png` through `panorama/5.png`: the six matching faces from the same classic Java title panorama. `HomePanorama` renders these as a slowly rotating skybox in the persistent root layout across all portfolio routes; `menu-panorama.png` remains the shared static fallback.
- `menu-stone.svg`: original deterministic pixel texture, generated for this portfolio's menu controls.
- The title uses original source-defined letter paths in `PortfolioTitle.tsx`.
