Homepage assets:

- `menu-pixel.otf`: Minecraft font by Idrees Hassan, https://github.com/IdreesInc/Minecraft-Font. Unmodified, bundled under the SIL Open Font License in `menu-pixel.LICENSE.txt`.
- `panorama/0.png` through `panorama/5.png`: the six matching faces from the same classic Java title panorama. `HomePanorama` renders these as a slowly rotating skybox in the persistent root layout across all portfolio routes; `panorama/2.png` is also the shared static fallback (the removed `menu-panorama.png` was identical).
- `menu-stone.svg`: original deterministic pixel texture, generated for this portfolio's menu controls.
- The title uses original source-defined letter paths in `PortfolioTitle.tsx`.
